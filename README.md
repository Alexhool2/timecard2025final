
# Electronic Time Clock System ⏱️

This is a work-in-progress project for an electronic time tracking system, built with Go and MySQL.

## 🚀 Features (MVP)

- Clock-in and clock-out functionality for employees
- Admin panel for managing and reviewing time logs
- Daily and weekly summary of worked hours
- Database storage for time records

## ⚙️ Tech Stack
-React + Bootstrap
-Typescrypt 
- Go (Golang)
- Nginx
- MySQL
- Docker (for local development)
- deployed on Alibaba vps
